# FJSS 1.5.9 — startup crash fix

- Fixed the malformed `CONTROLLER` icon command sequence in `LineIcon.java`.
- Added bounds/command validation in `LineIcon.draw()` so malformed drawing data cannot crash the TV home screen.
- Bumped Android version metadata to versionCode 22 / versionName 1.5.9.

The icon command arrays were statically checked: all 13 arrays have complete command sequences.

Build the APK with the repository's existing GitHub Actions workflow, or locally with Java 17 and Android SDK platform 34 / build-tools 34.0.0 using `sh build.sh`.
